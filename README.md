# IPP Printer Connect

안드로이드에서 네트워크 프린터로 PDF, 사진, TXT 파일을 출력하는 앱입니다. IPP로 프린터의 지원 형식을 확인하고, 원본을 보낼 수 없으면 프린터가 지원하는 형식으로 변환합니다.

현재 버전은 `1.0`입니다.

## 1.0 변경 사항

- 사진은 선택한 용지와 페이지 배치를 반영해 미리보기와 같은 크기로 준비합니다. 선명도는 선택한 출력 해상도에 따라 달라질 수 있습니다.
- TXT는 페이지를 나누어 처리하고 각 페이지에 원본 문서 기준 페이지 번호를 표시합니다. 페이지 범위 인쇄와 미리보기에서도 원래 번호를 유지합니다.
- 원본 파일이 프린터에서 직접 처리될 수 있고 앱의 페이지 재구성이 필요하지 않으면 원본 형식과 데이터를 유지합니다.
- 작업 접수와 실제 인쇄 완료를 구분하고, 확인할 수 있는 작업 상태를 표시합니다. 오류 상태를 감지해도 확인 없이 품질을 바꾸거나 다시 보내지 않습니다.
- 버전 표기를 `1.0`으로 확정했습니다.

## 0.9.23 변경 사항

- 사진을 PDF로 변환할 때는 원본 픽셀을 유지하고, PDF 페이지에 선택한 용지 크기와 배치만 기록합니다. PDF 출력에는 변환 DPI 선택이 필요하지 않습니다.
- 변환 DPI 선택은 JPEG·PostScript·PWG Raster·URF·PCL처럼 최종 출력이 픽셀 기반 형식일 때 표시합니다.

## 0.9.22 변경 사항

- 앱이 미리보기와 페이지 구성을 지원하는 PDF·사진·TXT만 앱 출력 경로로 처리합니다. 그 밖의 파일은 프린터가 형식을 광고하더라도 그대로 넘기지 않고 PDF로 변환해 다시 선택하도록 안내합니다.
- 프린터가 원본 사진·TXT를 광고해도 미리보기와 같은 페이지로 앱에서 준비합니다. PDF는 프린터가 PDF를 받으면 PDF 형식을 유지하고, 페이지 크기가 선택 용지와 다르면 미리보기와 같은 크기로 배치합니다. 다른 프린터 언어로 바꿔야 하는 PDF도 선택 용지에 맞춰 페이지를 만듭니다.
- 사진·TXT·프린터 미지원 PDF의 출력 형식은 프린터 광고와 색상 설정을 바탕으로 자동 선택합니다. 다른 지원 형식이 있으면 사용자가 직접 바꿀 수 있습니다.
- 변환 해상도는 기본 300dpi이며 PWG Raster·URF는 프린터가 광고한 해상도 중 300dpi에 가까운 값을 자동 선택합니다. 사용자는 변환 설정에서 다른 해상도를 선택할 수 있습니다.
- PostScript 기본 인코딩은 선택 용지 기준 300dpi와 JPEG 품질 100을 사용해 무압축 RGB 작업의 전송량을 줄입니다. 무손실 RGB와 다른 품질도 직접 선택할 수 있습니다.
- PDF 페이지 크기가 선택 용지와 다르면 변환 경로에서 용지에 맞춰 배치합니다. 주석·입력란을 안전하게 보존할 수 없는 변환은 중단하고 평면화한 PDF 또는 프린터의 PDF 직접 지원을 안내합니다.

## 0.9.21 변경 사항

- 사진은 선택한 용지 크기의 페이지로 준비해 미리보기와 같은 배치를 유지합니다. 용지 크기 기준 300dpi를 넘는 사진은 자동으로 줄여 큰 JPEG의 처리량과 프린터 메모리 부담을 낮춥니다.
- JPEG를 PDF로 보낼 때 사진을 RGB 픽셀로 풀어 PDF 크기가 불필요하게 커지지 않도록 JPEG 압축 데이터를 유지합니다. 축소가 필요할 때만 페이지에 필요한 크기로 다시 인코딩합니다.
- JPEG·PNG·PostScript 등 사진 출력용 형식은 300dpi, PWG Raster·URF는 프린터가 광고한 해상도 중 300dpi에 가장 가까운 지원값을 사용합니다.
- 사진 외의 PDF·PostScript·PCL·텍스트 파일은 프린터가 원본 형식을 지원하고 사용자가 문서 변경을 요청하지 않으면 원본 그대로 전송합니다.

## 0.9.19 변경 사항

- 사진은 선택한 용지에 미리보기와 같은 배치로 준비해서 보냅니다. 기본 설정에서도 여백·위치·내용 회전을 실제 인쇄에 적용합니다.
- JPEG·PNG를 지원하는 프린터에는 같은 형식으로 저장합니다. 출력 이미지 크기는 선택한 용지와 인쇄용 변환 해상도로 계산하며 화면에 픽셀 크기를 표시합니다.
- 미리보기용 축소 이미지는 인쇄에 사용하지 않습니다. 인쇄용 해상도를 고르기 전에도 사진 배치를 미리 볼 수 있습니다.
- 접수된 작업의 상태를 조회해 대기·처리·완료·취소·중단을 표시합니다. 상태 확인 실패를 인쇄 실패로 처리하거나 자동 재전송하지 않습니다.
- 상태 조회는 최대 5분 동안 진행합니다. 조회가 끝나면 버튼으로 다시 확인할 수 있습니다. 앱을 종료하면 추적은 중단됩니다.

## 0.9.18 변경 사항

- JPEG 원본 형식을 유지하며 페이지 배치를 적용할 때 선택한 JPEG 품질을 인코더에 전달합니다. 변환 준비가 전송 전에 실패하던 경로를 수정했습니다.

## 0.9.17 변경 사항

- 기본 용지를 선택하면 프린터가 알려준 용지 값을 인쇄 요청에도 명시합니다. 미리보기와 전송에 같은 용지 값을 사용합니다.
- 기본 용지 정보가 없으면 ‘프린터에 맡김 (기본 용지 정보 없음)’으로 표시하고 용지 지정은 생략합니다.

## 0.9.16 변경 사항

- 문서 준비 취소 버튼과 미리보기·인쇄하기 버튼 사이에 간격을 추가했습니다.
- 인쇄 버튼 아래에 진행 상태와 접수 결과, 작업 번호를 표시합니다. 접수는 실제 출력 완료와 구분해 안내합니다.

## 0.9.15 변경 사항

- 프린터가 원본 MIME을 지원하면 앱에서 배치할 때도 해당 형식으로 결과를 만듭니다. PDF는 PDF, PNG는 PNG, JPEG는 JPEG를 유지합니다.
- 원본 형식으로 변환할 수 없는 파일에만 다른 출력 형식 선택을 표시합니다.
- 용지 크기·출력 방향은 IPP 옵션으로 보내고, 페이지 배치를 실제로 바꾸는 설정만 앱에서 문서에 적용합니다.
- JPEG·PNG 같은 래스터 형식은 변환 시 해상도를 선택하도록 하고 지원 광고와 맞지 않는 조합은 안내합니다.

실제 출력 검증은 아직 하지 않았습니다. 상세 내용은 [0.9.15 수정 내역](docs/0.9.15_수정내역.md)에 있습니다.

## 0.9.14 변경 사항

- 흑백 기본값 유지
- PDF의 페이지 선택·배치·모아찍기를 글자와 벡터를 유지하는 방식으로 변경. 페이지 범위만 지정하면 원래 페이지 크기와 배치를 유지
- PostScript 형식 표기 차이로 압축 설정이 숨겨지던 문제 수정. 기본은 무손실 RGB이며 JPEG 압축은 선택할 때만 적용
- 용지 크기나 여백을 알 수 없을 때 A4·5mm 등으로 대신 처리하지 않도록 변경. 확인된 좌우·상하 여백은 각각 적용
- 앱에서 배치하는 문서는 페이지 배치에서 맞춤·위치를 설정하도록 통합
- 미리보기에 흑백과 PCL의 단색 변환 반영. 화면용 축소 데이터는 실제 인쇄에 사용하지 않음
- PWG Raster·URF의 세부 지원 정보 확인. 지원하지 않거나 확인되지 않은 조합은 이유를 안내하고 중단
- 설정 대체 경고, 전송 거절, 접수 여부 확인 불가를 구분. 준비 중 취소와 앱 재실행 시 중단 안내 추가
- IPP 응답 크기 제한, 잘린 응답 검출, PDF 인덱스의 디스크 저장, 이전 작업 임시 파일 정리
- 변환 설정 복원과 파일 확인 중 인쇄 차단, 잘못된 복사 매수 처리 수정

PDF 편집에는 [PdfBox-Android](https://github.com/TomRoush/PdfBox-Android) 2.0.27.0(Apache-2.0)을 사용합니다. 주석·입력란 또는 특수 좌표 단위가 있는 PDF의 배치 변경과 다중 프레임 이미지 변환은 현재 지원하지 않으며, 내용을 누락한 채 출력하지 않고 안내합니다. 원본 전송은 별도 경로입니다.

0.9.14는 APK와 검사 코드의 컴파일을 확인한 버전입니다. 이번 수정 후 기기·출력 검사는 아직 수행하지 않았습니다. 상세 변경점과 확인할 항목은 [0.9.14 수정 내역](docs/0.9.14_수정내역.md)에 정리했습니다. 아래는 이전 버전의 당시 변경 기록입니다.

## 0.9.11 변경 사항

- 앱 변환 해상도는 파일을 프린터가 그대로 처리하는 경우 비활성화하고, 앱이 실제로 변환하거나 페이지 배치를 적용할 때만 선택 가능
- 파일 형식, 프린터 지원 형식, PostScript 전송 여부, 용지·페이지 배치 설정에 따라 활성 상태를 갱신

## 0.9.10 변경 사항

- TXT 변환은 파일을 조금씩 읽고 한 페이지씩 PDF로 저장. 전체 문자열과 모든 페이지를 메모리에 모으지 않도록 변경
- 한글 글자와 줄바꿈·페이지 배치는 유지하고, TXT를 PDF로 만들 때 글자를 이미지로 바꾸지 않음
- 최종 PNG·JPEG 변환도 작은 띠와 행 단위로 처리. 높은 DPI의 페이지 전체를 비트맵 하나로 만들지 않음
- 실제 출력의 선택 DPI와 JPEG 품질은 유지. 미리보기는 별도의 화면용 해상도를 사용
- 변환 취소·저장 오류 시 파일과 압축기 자원 정리

PNG는 무손실 압축이며, JPEG 100도 무손실 형식은 아닙니다. JPEG는 전체 이미지의 압축 계수를 보관하는 최적화를 끈 대신, 같은 품질 설정에서도 파일 크기가 이전보다 커질 수 있습니다.

저장 공간과 프린터의 처리 한계는 남아 있습니다. JPEG는 가로·세로 각각 65,500픽셀까지 처리하며, 이를 넘으면 해상도를 임의로 낮추지 않고 이유를 안내합니다. JPEG·PNG 한 파일로 여러 페이지를 전송하지는 않습니다.

## 0.9.9 변경 사항

- 문서를 캐시 파일로 준비하고 IPP 헤더와 파일을 순서대로 전송하도록 변경. Digest 인증도 문서 전체를 복사하지 않고 해시 계산
- 입력 파일과 변환 결과의 고정 50 MiB 제한 제거
- 큰 사진의 인쇄용 변환은 원본을 타일 단위로 읽고, PDF 배치·모아찍기와 PostScript·PWG Raster·URF·PCL 변환은 작은 띠 단위로 처리
- 실제 인쇄의 선택 DPI와 PostScript 이미지 품질은 유지. 메모리가 부족하다고 자동으로 품질을 낮추지 않음
- 컬러를 요청한 작업에 흑백 전용 PCL 변환을 사용하지 않도록 수정. 다른 형식으로 컬러를 유지할 수 없으면 이유를 안내
- PCL 변환에 실제 용지와 가로·세로 방향 명시. 지원하지 않는 사용자 지정 용지는 다른 크기로 바꾸지 않고 안내
- 프린터 기본값 때문에 앱에서 완성한 페이지에 배치가 다시 적용될 수 있고 이를 해제할 수 없으면 전송 전에 실패 안내
- 전송·미리보기의 임시 파일을 작업 종료·실패·취소 시 정리

고정 파일 크기 제한을 없앤 것이 모든 크기의 문서를 처리할 수 있다는 뜻은 아닙니다. 휴대폰 저장 공간·메모리와 프린터의 한계는 남아 있습니다. 이 버전에 남아 있던 TXT 전체 문서 보관과 최종 JPEG·PNG의 전체 페이지 비트맵 처리는 0.9.10에서 변경했습니다. 미리보기용 축소 데이터는 실제 인쇄에 사용하지 않습니다.

## 0.9.8 변경 사항

- 사진 미리보기는 화면용 크기로 읽고, 실제 전송용 원본과 분리
- PDF 배치·모아찍기 미리보기도 인쇄 DPI 대신 화면용 해상도 사용
- 세로로 긴 PDF도 미리보기 이미지의 너비·높이를 모두 제한
- 사진을 축소해 미리 보더라도 원본 크기·여백·회전·잘림 배치는 유지
- 내용 회전은 비트맵을 복사하지 않고 화면에 그리는 좌표만 변환
- 중복 미리보기 생성 취소, 문서·프린터·설정을 바꾼 뒤 이전 결과가 뜨는 문제 수정
- 인쇄 준비와 미리보기 생성이 동시에 큰 이미지를 읽지 않도록 정리

화면용 미리보기 데이터는 인쇄에 재사용하지 않습니다. 실제 전송은 원본 또는 사용자가 선택한 인쇄 해상도로 다시 준비합니다. 프린터의 출력 형식 설정에 문제가 있어도 문서 미리보기는 볼 수 있으며, 해당 문제는 안내하고 인쇄할 때 다시 검사합니다.

## 0.9.7 변경 사항

- 문서 선택 화면에서 텍스트 파일 인코딩 선택과 텍스트 전용 설명 삭제
- 변환·미리보기에 필요한 문자 인코딩은 내부에서 자동 판별
- TXT 파일 선택·인쇄와 미지원 프린터용 자동 변환은 그대로 유지

## 0.9.6 변경 사항

- 텍스트 파일의 글자 크기·배치 적용 체크박스와 글자 크기 입력 삭제
- TXT는 다른 문서처럼 파일 선택 후 인쇄. 프린터가 원문을 지원하면 원본 전송, 미지원이면 자동 변환
- 변환이 필요한 긴 텍스트는 기본 글자 크기로 페이지를 나누어 출력
- TXT 변환 시 파일명을 문서 제목으로 추가하지 않고 파일 내용만 출력

원본 파일은 수정하지 않습니다. 기존 용지·페이지 배치·양면·컬러와 인쇄 품질 설정은 유지합니다.

## 0.9.5 변경 사항

- 화면 회전·재생성 후 선택한 프린터, 문서와 인쇄 설정 복원
- 화면이 다시 열려도 준비·전송 중인 인쇄 요청을 다시 보내지 않고 기존 진행 상태 표시
- PDF·사진·TXT의 페이지 범위와 모아찍기는 프린터 지원 광고와 관계없이 앱에서 처리
- 사진의 EXIF 회전·반전을 미리보기와 변환에 반영
- TXT 변환 시 UTF-8·CP949·UTF-16 읽기 지원. 자동 판별과 직접 선택 제공
- 문서 URL 인쇄는 Print-URI 또는 Create-Job/Send-URI 지원 여부로 확인

앱이 재배치할 수 없는 파일과 문서 URL은 프린터가 지원하는 페이지 옵션만 사용합니다. TXT 원문을 그대로 전송하는 경우에는 프린터가 인코딩을 해석하고, 앱에서 변환하거나 미리 볼 때는 자동 판별합니다. 사진 원본 전송에서도 EXIF 방향 해석은 프린터에 맡깁니다.

진행 중인 작업 유지는 같은 앱 프로세스 안의 화면 재생성에 해당합니다. 앱 프로세스가 종료된 뒤에는 중복 출력을 막기 위해 자동으로 다시 전송하지 않습니다.

## 0.9.4 변경 사항

- 이름 설정·문서 준비·로그인·전송이 끝날 때까지 인쇄 버튼 중복 실행 방지
- 버튼을 누른 시점의 파일과 설정으로 전송하고, 취소나 오류가 나면 다시 인쇄 가능
- 형식 불명 파일을 프린터의 자동 감지 광고만으로 전송하던 처리 수정
- PDF·사진 등은 파일 헤더를 먼저 확인하고, 판별·변환할 수 없는 파일은 이유와 함께 실패 안내

파일 선택은 계속 모든 형식에 열려 있습니다.

## 0.9.3 변경 사항

- 미리보기에 이전·다음 버튼과 현재/전체 페이지 표시 추가
- 페이지 범위와 모아찍기를 적용한 출력 문서의 뒷장도 확인 가능
- 페이지는 한 장씩 불러오고, 창을 닫으면 미리보기 메모리와 임시 파일 정리

## 0.9.2 변경 사항

- 여백·회전·배율·위치 등을 바꾸면 프린터가 원본 형식을 지원해도 배치를 적용한 문서를 전송
- 미리보기와 전송 문서에 같은 페이지 생성 과정 사용
- 페이지 범위와 모아찍기를 변환 형식에 관계없이 앱에서 적용
- 변환 과정에서 여백·회전이 다시 적용되거나 프린터가 모아찍기를 반복하지 않도록 수정
- JPEG·PNG만 지원하는 프린터에는 배치한 한 페이지를 이미지로 전송. 여러 페이지는 이미지 한 장으로 보내지 않고 오류 안내

배치 변경이 없고 원본 형식을 지원하면 원본 전송을 유지합니다. 원본 전송 미리보기에는 실제 배치를 프린터에서 처리한다는 안내가 표시됩니다. 앱이 배치할 수 없는 파일이나 전송 형식이 없으면 실패 이유를 표시합니다.

## 0.9.1 변경 사항

- 실험할 때 쓰던 직접 텍스트 입력 기능 삭제
- TXT 파일 출력은 유지. 글자 크기 설정과 자동 페이지 나누기도 사용 가능
- 파일과 문서 URL은 둘 중 하나만 선택

파일 선택에는 형식 제한을 두지 않았습니다. 다만 모든 파일을 출력할 수 있는 것은 아닙니다. 프린터가 원본을 지원하지 않고 앱에서도 변환할 수 없으면, 전송 전에 이유를 표시합니다.

## 0.9.0 변경 사항

- 텍스트 글자 크기 설정, 긴 글 자동 페이지 나누기 추가
- 변환 해상도 선택: 75 / 150 / 300 / 600 / 1200 dpi
- PostScript 이미지 품질 선택: JPEG 90 / JPEG 100 / 무손실 RGB
- 큰 사진의 자동 축소 제거. 메모리나 파일 크기 한도를 넘으면 오류 표시
- PDF 배치 변환을 끌 수 있도록 수정

글자 크기와 페이지 나누기는 앱에서 텍스트를 문서로 변환할 때 적용됩니다. 텍스트 원문을 그대로 보내면 프린터가 글꼴과 배치를 정합니다. 변환 해상도는 프린터에 요청하는 IPP 해상도와 별도이며, PCL 변환에서는 1200 dpi를 지원하지 않습니다.

원본 형식을 프린터가 지원하면 원본 전송을 우선합니다. 용지·여백·배율·위치·회전·페이지 선택을 바꾸거나 PostScript 변환을 선택하면 설정을 반영한 문서를 만듭니다. PDF 배치 변환 체크는 기본 배치 적용 여부이며, 체크를 꺼도 변경한 배치 설정은 반영합니다.

## 주요 기능

- 현재 Wi-Fi에서 mDNS로 IPP·IPPS 프린터 검색
- IP 주소 또는 IPP 주소를 이용한 직접 연결
- 지정한 네트워크 범위에서 프린터 검색
- 프린터가 지원하는 문서 형식과 인쇄 옵션 조회
- PDF, 사진, 텍스트 파일 선택 및 미리보기
- 프린터가 원본 파일을 지원하지 않을 때 PDF, PostScript, PWG Raster, URF, PCL 등으로 변환
- 용지 크기, 인쇄 방향, 컬러, 양면 인쇄, 여백과 페이지 배치 설정
- 실제로 인쇄를 요청한 프린터 저장 및 이름 변경
- HTTP Basic·Digest 인증이 필요한 프린터 연결

## 사용 방법

1. 휴대폰과 프린터를 같은 네트워크에 연결합니다.
2. 앱에서 `현재 Wi-Fi에서 프린터 찾기`를 누릅니다.
3. 검색된 프린터를 선택합니다.
4. 출력할 문서와 인쇄 옵션을 정한 뒤 미리보기로 결과를 확인합니다.
5. `인쇄하기`를 눌러 작업을 전송합니다.

자동 검색이 되지 않으면 `추가 연결 방법`에서 프린터의 IP 주소를 직접 입력하거나 네트워크 범위를 검색할 수 있습니다.

## 주의사항

이 앱은 본인이 관리하거나 사용 허가를 받은 네트워크와 프린터에서 사용해야 합니다.

일반 IPP 연결은 암호화되지 않은 HTTP를 사용할 수 있습니다. 신뢰할 수 없는 네트워크에서는 문서나 인증 정보가 노출될 수 있으므로, 가능하면 인증서가 정상적으로 설정된 IPPS 연결을 사용하는 것이 좋습니다.

mDNS 검색은 프린터가 IPP 서비스를 광고하고 네트워크에서 멀티캐스트 통신을 허용할 때 동작합니다. 게스트 Wi-Fi, AP 격리, VLAN 분리 환경에서는 같은 공유기에 연결되어 있어도 검색되지 않을 수 있습니다.
