# IPP Printer Connect

안드로이드에서 네트워크 프린터로 PDF, 사진, TXT 파일을 출력하는 앱입니다. IPP로 프린터의 지원 형식을 확인하고, 원본을 보낼 수 없으면 프린터가 지원하는 형식으로 변환합니다.

현재 버전은 `0.9.7`입니다.

## 0.9.7 변경 사항

- 문서 선택 화면에서 텍스트 파일 인코딩 선택과 텍스트 전용 설명 삭제
- 변환·미리보기에 필요한 문자 인코딩은 내부에서 자동 판별
- TXT 파일 선택·인쇄와 미지원 프린터용 자동 변환은 그대로 유지

## 0.9.6 변경 사항

- 텍스트 파일의 글자 크기·배치 적용 체크박스와 글자 크기 입력 삭제
- TXT는 다른 문서처럼 파일 선택 후 인쇄. 프린터가 원문을 지원하면 원본 전송, 미지원이면 자동 변환
- 변환이 필요한 긴 텍스트는 기본 글자 크기로 페이지를 나누어 출력
- TXT 변환 시 파일명을 문서 제목으로 추가하지 않고 파일 내용만 출력

원본 파일은 수정하지 않습니다. 기존 용지·페이지 배치·양면·컬러와 인쇄 품질 설정은 유지합니다.

## 0.9.5 변경 사항

- 화면 회전·재생성 후 선택한 프린터, 문서와 인쇄 설정 복원
- 화면이 다시 열려도 준비·전송 중인 인쇄 요청을 다시 보내지 않고 기존 진행 상태 표시
- PDF·사진·TXT의 페이지 범위와 모아찍기는 프린터 지원 광고와 관계없이 앱에서 처리
- 사진의 EXIF 회전·반전을 미리보기와 변환에 반영
- TXT 변환 시 UTF-8·CP949·UTF-16 읽기 지원. 자동 판별과 직접 선택 제공
- 문서 URL 인쇄는 Print-URI 또는 Create-Job/Send-URI 지원 여부로 확인

앱이 재배치할 수 없는 파일과 문서 URL은 프린터가 지원하는 페이지 옵션만 사용합니다. TXT 원문을 그대로 전송하는 경우에는 프린터가 인코딩을 해석하고, 앱에서 변환하거나 미리 볼 때는 자동 판별합니다. 사진 원본 전송에서도 EXIF 방향 해석은 프린터에 맡깁니다.

진행 중인 작업 유지는 같은 앱 프로세스 안의 화면 재생성에 해당합니다. 앱 프로세스가 종료된 뒤에는 중복 출력을 막기 위해 자동으로 다시 전송하지 않습니다.

## 0.9.4 변경 사항

- 이름 설정·문서 준비·로그인·전송이 끝날 때까지 인쇄 버튼 중복 실행 방지
- 버튼을 누른 시점의 파일과 설정으로 전송하고, 취소나 오류가 나면 다시 인쇄 가능
- 형식 불명 파일을 프린터의 자동 감지 광고만으로 전송하던 처리 수정
- PDF·사진 등은 파일 헤더를 먼저 확인하고, 판별·변환할 수 없는 파일은 이유와 함께 실패 안내

파일 선택은 계속 모든 형식에 열려 있습니다.

## 0.9.3 변경 사항

- 미리보기에 이전·다음 버튼과 현재/전체 페이지 표시 추가
- 페이지 범위와 모아찍기를 적용한 출력 문서의 뒷장도 확인 가능
- 페이지는 한 장씩 불러오고, 창을 닫으면 미리보기 메모리와 임시 파일 정리

## 0.9.2 변경 사항

- 여백·회전·배율·위치 등을 바꾸면 프린터가 원본 형식을 지원해도 배치를 적용한 문서를 전송
- 미리보기와 전송 문서에 같은 페이지 생성 과정 사용
- 페이지 범위와 모아찍기를 변환 형식에 관계없이 앱에서 적용
- 변환 과정에서 여백·회전이 다시 적용되거나 프린터가 모아찍기를 반복하지 않도록 수정
- JPEG·PNG만 지원하는 프린터에는 배치한 한 페이지를 이미지로 전송. 여러 페이지는 이미지 한 장으로 보내지 않고 오류 안내

배치 변경이 없고 원본 형식을 지원하면 원본 전송을 유지합니다. 원본 전송 미리보기에는 실제 배치를 프린터에서 처리한다는 안내가 표시됩니다. 앱이 배치할 수 없는 파일이나 전송 형식이 없으면 실패 이유를 표시합니다.

## 0.9.1 변경 사항

- 실험할 때 쓰던 직접 텍스트 입력 기능 삭제
- TXT 파일 출력은 유지. 글자 크기 설정과 자동 페이지 나누기도 사용 가능
- 파일과 문서 URL은 둘 중 하나만 선택

파일 선택에는 형식 제한을 두지 않았습니다. 다만 모든 파일을 출력할 수 있는 것은 아닙니다. 프린터가 원본을 지원하지 않고 앱에서도 변환할 수 없으면, 전송 전에 이유를 표시합니다.

## 0.9.0 변경 사항

- 텍스트 글자 크기 설정, 긴 글 자동 페이지 나누기 추가
- 변환 해상도 선택: 75 / 150 / 300 / 600 / 1200 dpi
- PostScript 이미지 품질 선택: JPEG 90 / JPEG 100 / 무손실 RGB
- 큰 사진의 자동 축소 제거. 메모리나 파일 크기 한도를 넘으면 오류 표시
- PDF 배치 변환을 끌 수 있도록 수정

글자 크기와 페이지 나누기는 앱에서 텍스트를 문서로 변환할 때 적용됩니다. 텍스트 원문을 그대로 보내면 프린터가 글꼴과 배치를 정합니다. 변환 해상도는 프린터에 요청하는 IPP 해상도와 별도이며, PCL 변환에서는 1200 dpi를 지원하지 않습니다.

원본 형식을 프린터가 지원하면 원본 전송을 우선합니다. 용지·여백·배율·위치·회전·페이지 선택을 바꾸거나 PostScript 변환을 선택하면 설정을 반영한 문서를 만듭니다. PDF 배치 변환 체크는 기본 배치 적용 여부이며, 체크를 꺼도 변경한 배치 설정은 반영합니다.

## 주요 기능

- 현재 Wi-Fi에서 mDNS로 IPP·IPPS 프린터 검색
- IP 주소 또는 IPP 주소를 이용한 직접 연결
- 지정한 네트워크 범위에서 프린터 검색
- 프린터가 지원하는 문서 형식과 인쇄 옵션 조회
- PDF, 사진, 텍스트 파일 선택 및 미리보기
- 프린터가 원본 파일을 지원하지 않을 때 PDF, PostScript, PWG Raster, URF, PCL 등으로 변환
- 용지 크기, 인쇄 방향, 컬러, 양면 인쇄, 여백과 페이지 배치 설정
- 실제로 인쇄를 요청한 프린터 저장 및 이름 변경
- HTTP Basic·Digest 인증이 필요한 프린터 연결

## 사용 방법

1. 휴대폰과 프린터를 같은 네트워크에 연결합니다.
2. 앱에서 `현재 Wi-Fi에서 프린터 찾기`를 누릅니다.
3. 검색된 프린터를 선택합니다.
4. 출력할 문서와 인쇄 옵션을 정한 뒤 미리보기로 결과를 확인합니다.
5. `인쇄하기`를 눌러 작업을 전송합니다.

자동 검색이 되지 않으면 `추가 연결 방법`에서 프린터의 IP 주소를 직접 입력하거나 네트워크 범위를 검색할 수 있습니다.

- Android Studio

Android Studio에서 프로젝트 폴더를 열고 Gradle 동기화 후 실행하면 됩니다.

## 확인한 환경

개발 단말은 Samsung SM-A556S입니다. 프린터마다 지원 형식과 옵션이 달라 기종별 확인이 필요합니다. 실제 출력 결과는 프린터에서 확인해야 합니다.

## 주의사항

이 앱은 본인이 관리하거나 사용 허가를 받은 네트워크와 프린터에서 사용해야 합니다.

일반 IPP 연결은 암호화되지 않은 HTTP를 사용할 수 있습니다. 신뢰할 수 없는 네트워크에서는 문서나 인증 정보가 노출될 수 있으므로, 가능하면 인증서가 정상적으로 설정된 IPPS 연결을 사용하는 것이 좋습니다.

mDNS 검색은 프린터가 IPP 서비스를 광고하고 네트워크에서 멀티캐스트 통신을 허용할 때 동작합니다. 게스트 Wi-Fi, AP 격리, VLAN 분리 환경에서는 같은 공유기에 연결되어 있어도 검색되지 않을 수 있습니다.
