# 0.9.11 수정 내역

앱 변환 해상도 선택을 실제 변환 여부와 연결했다.

- 파일을 선택하지 않았거나 문서 URL을 사용하는 동안에는 앱 변환 해상도를 비활성화한다.
- 프린터가 선택한 원본 형식을 지원하고 앱에서 페이지를 바꾸지 않으면 원본 그대로 보낸다. 이 경우 변환 해상도는 사용되지 않으므로 비활성화한다.
- 프린터가 원본 형식을 지원하지 않아 앱 변환이 필요하거나, PostScript 전송·페이지 배치 변경으로 앱이 문서를 다시 만들 때 활성화한다.
- 프린터, 문서, PostScript 선택, 페이지·용지 옵션 변경에 따라 활성 상태를 다시 계산한다.
- 앱 버전은 0.9.11, versionCode는 101이다.
