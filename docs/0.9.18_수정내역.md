# 0.9.18 수정 내역

## JPEG 배치 출력 수정

프린터가 JPEG를 지원하고 페이지 배치를 적용할 때 원본 MIME인 `image/jpeg`를 출력 형식으로 유지한다. 이때 화면에는 JPEG 품질과 변환 해상도가 표시되지만, 인코더에 전달할 품질을 만드는 코드가 변환 형식 선택창의 MIME만 참조했다. 원본 형식을 유지하는 경로에는 별도 형식 선택값이 없으므로 품질이 `null`로 전달됐고, JPEG 인코더가 파일 준비 단계에서 중단될 수 있었다. 따라서 IPP 작업이 프린터까지 도달하지 않아 프린터가 반응하지 않는 것처럼 보일 수 있었다.

이제 원본 MIME을 유지하는 페이지 배치 경로에서는 선택한 파일의 MIME을 품질 설정에 사용한다. JPEG이면 사용자가 선택한 품질 100 또는 90을 인코더에 전달한다. 프린터가 원본 JPEG를 직접 지원하지만 페이지 배치가 필요하지 않은 경우에는 계속 원본 파일을 그대로 보낸다.

0.9.16의 인쇄 상태 표시와 0.9.17의 기본 용지 요청 수정도 포함한다. 빌드 완료 후 실제 프린터 출력은 확인하지 않았다.
