# 0.9.17 수정 내역

## 기본 용지 전송

기존에는 ‘프린터 기본값’을 선택하면 미리보기에는 media-default를 사용하면서도 IPP 요청에서는 media를 생략했다. 사용자가 A4를 직접 고르면 인쇄되지만 기본값에서는 프린터에서 용지함을 선택해야 한다는 현상이 보고됐다.

기본 용지 선택 시 프린터가 알려준 media-default를 media 속성으로 전송하도록 변경했다. 미리보기 용지 크기, 광고 여백 조회, 실제 전송이 같은 선택 값을 사용한다. 프린터가 기본 용지를 알려주지 않으면 임의의 크기를 정하지 않고 ‘프린터에 맡김 (기본 용지 정보 없음)’으로 표시한다. 용지함이나 용지 종류를 강제로 지정하지 않는다.

0.9.16의 문서 준비 취소 버튼 간격과 인쇄 버튼 아래 상태 표시도 포함한다.

실제 프린터의 용지함 선택 대기가 해소됐는지는 사용자 출력 확인이 필요하다.
