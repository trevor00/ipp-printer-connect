# 0.9.15 수정 내역

버전: 0.9.15 / versionCode 105

프린터가 원본 파일의 MIME 형식을 지원하면, 사용자가 페이지 배치 변경을 요청해도 앱이 같은 MIME 형식으로 결과 파일을 만든다. 예를 들어 지원되는 PDF는 PDF로, JPEG는 JPEG로 유지한다. 그 파일 형식으로 결과를 만들 수 없는 경우에만 다른 변환 형식을 선택하게 한다.

용지 크기와 출력 방향은 IPP 작업 옵션이므로 그 값만 바꾼 경우 원본 문서를 앱에서 다시 만들지 않는다. 페이지 크기·정렬·여백·배율·회전, 페이지 범위, 모아찍기처럼 문서 페이지 자체를 변경하는 경우에만 앱이 문서를 준비한다.

원본 JPEG를 다시 JPEG로 만들거나 PNG를 다른 해상도로 다시 만들 때는 형식은 유지되지만 픽셀 데이터는 다시 만들어진다. JPEG는 선택한 품질 값의 손실 압축을 사용하고, PNG는 무손실 압축을 사용한다. 래스터 출력에는 DPI 선택이 필요하며, 임의로 낮춰 대체하지 않는다.

이번 버전은 코드 수정과 APK 컴파일을 확인했다. 사용자가 실기 테스트를 맡기로 했으므로 테스트 실행, 휴대폰 설치, 프린터 출력은 하지 않았다.
