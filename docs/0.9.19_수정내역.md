# 0.9.19

## 사진 배치

사진을 골랐을 때 옵션을 바꾸지 않으면 미리보기만 용지에 맞춰 만들고, 실제 전송은 원본 JPEG를 보내던 경로를 수정했다. 사진은 기본 설정에서도 선택한 용지·여백·위치·회전·크기 조절을 적용한 페이지로 만든다. JPEG·PNG를 지원하는 프린터에는 같은 형식으로 보낸다.

출력 픽셀 크기는 사진의 원래 가로·세로 크기가 아니라 선택한 용지와 인쇄용 해상도로 계산한다. 앱의 A4 좌표(595×842pt)에서는 300dpi일 때 2479×3508px, 600dpi일 때 4958×7017px이다. 다른 용지도 해당 크기를 사용한다. 해상도 선택 아래에 계산된 픽셀 크기를 표시한다.

미리보기와 인쇄는 같은 배치 계산을 사용한다. 미리보기는 화면용으로 축소해서 만들고, 인쇄는 원본 파일에서 선택한 해상도로 별도 생성한다. 인쇄용 이미지는 타일·띠 단위로 처리하는 기존 경로를 사용한다. JPEG는 재저장 과정에서 손실 압축을 사용하며 선택한 품질을 적용한다.

## 작업 상태

프린터가 작업을 접수하면 받은 작업 번호로 Get-Job-Attributes를 조회한다. 대기·처리·일시 중지·완료·취소·중단과 프린터가 알려준 완료 매수를 표시한다. 중단 사유가 없으면 사유를 알려주지 않았다고 표시한다.

조회는 2초 간격으로 최대 5분 동안 진행한다. 연속 3회 조회 실패 또는 시간 초과 시 확인 버튼을 제공한다. 접수 후 상태를 모르는 경우를 인쇄 실패로 단정하지 않는다. 상태 조회로 품질을 바꾸거나 작업을 재전송하지 않는다.

현재 화면에서는 가장 최근에 보낸 작업을 추적한다. 새 작업을 시작하면 이전 작업 추적을 끝낸다. 화면 재생성 중에는 추적을 유지하지만 앱 프로세스가 종료되면 추적을 중단한다. 프린터의 완료 보고와 사용자가 확인한 실제 출력은 구분한다.

## 확인 범위

디버그 APK 빌드와 관련 JVM 단위 검사 59개를 통과했다. 사진 출력 경로 선택, 배치 옵션, 미리보기 해상도 분리, 래스터 순차 출력, IPP 작업 상태 해석과 조회 요청을 확인했다.

실물 출력과 휴대폰 조작은 사용자가 확인한다. 휴대폰 설치나 실제 인쇄는 진행하지 않았다. 장치별 물리 여백·색 재현의 차이까지 동일하다고 보장하는 것은 아니다.
